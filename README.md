# 옷장 거울

옷장 옆 거울 근처에 태블릿을 세워 두고 쓰는 코디 도우미입니다. 옷을 하나 입고 화면 앞에 서면 지금 입은 옷을 기준으로, 오늘 날씨·분위기·일정에 맞춰 **"이것만 바꿔보세요"**를 내 옷장 안에서 1~3개 골라 줍니다. 2주 사용자 검증용 MVP입니다.

## 할 수 있는 것

| 화면 | 기능 |
|---|---|
| 오늘 | 날씨, 분위기 3개(편하게·단정하게·기분 내게), 일정 한 줄(음성 가능), 입은 옷 촬영 또는 직접 선택, 추천 카드, 입음·그대로·안 입음 기록 |
| 옷장 | 사진으로 등록(AI가 종류·색·두께·스타일 채움), 여러 장 한꺼번에 등록, 수정, 세탁 중 표시 |
| 기록 | 사용한 날, 추천대로 입은 비율, 1주차→2주차 비교, 자주 입은 옷, 한동안 안 입은 옷, CSV 저장, 백업 |
| 설정 | 가족 프로필, 가구 ID, 샘플 옷장 |

## 돌아가는 방식 세 가지

같은 화면 코드가 환경에 따라 다르게 동작합니다.

| 환경 | AI | 날씨 | 저장 | 카메라 |
|---|---|---|---|---|
| Claude 아티팩트 | 보는 사람의 Claude | 직접 입력 | Claude 계정(기기 간 공유) | 기기 카메라 앱으로 촬영 |
| 직접 띄운 서버 + API 키 | 서버의 Claude API | 자동(Open-Meteo) | 그 기기의 브라우저 | 화면에서 3초 뒤 자동 촬영 |
| 서버만(키 없음) | 없음. 내장 규칙으로 추천 | 자동 | 그 기기의 브라우저 | 입은 옷을 직접 선택 |

AI가 없어도 기온·분위기·색 조합 규칙으로 추천이 나옵니다. AI가 답을 못 주거나 엉뚱한 옷을 고르면 규칙 추천으로 넘어갑니다.

## 직접 띄우기

Node 20 이상이 필요합니다.

```bash
npm install
cp .env.example .env   # ANTHROPIC_API_KEY를 넣는다
node --env-file=.env server.mjs
```

`http://localhost:3000`을 엽니다. 태블릿에서 카메라를 쓰려면 HTTPS 주소가 필요하므로, Node 서버를 올릴 수 있는 호스팅에 배포하고 `ANTHROPIC_API_KEY`와 `ACCESS_CODE`를 비밀 값으로 설정하세요. `ACCESS_CODE`를 정하면 앱 설정 화면에 같은 코드를 넣은 기기만 AI를 씁니다.

```bash
npm test        # 추천 엔진 테스트
npm run build   # dist/closet-mirror.html (아티팩트용), dist/index.html
```

## 코드 구조

| 파일 | 역할 |
|---|---|
| `src/shared/engine.cjs` | 추천 규칙, AI 응답 검증, 통계, CSV. 화면과 무관한 순수 함수 |
| `src/shared/prompts.cjs` | AI 지시문과 응답 해석. 브라우저와 서버가 같이 씀 |
| `src/js/platform.js` | 저장소, AI, 날씨, 음성, 파일 저장을 환경에 맞게 연결 |
| `src/js/ui.js` | 화면 |
| `server.mjs` | 화면 제공, `/api/ai/tag`, `/api/ai/look`, `/api/weather` |
| `build.mjs` | 소스 조각을 한 장의 페이지로 합침 |

## 개인정보

- 입은 모습을 찍은 사진은 추천을 받는 동안만 쓰고 저장하지 않습니다. AI가 연결돼 있으면 그 사진은 Claude로 전송됩니다.
- 옷장에는 옷 사진의 작은 축소본(긴 변 360px)만 남습니다.
- API 키는 서버 환경변수에만 있고 브라우저로 내려가지 않습니다.

## 아직 안 된 것

- 실제 Claude API와 실제 아티팩트 화면에서의 AI 호출은 개발 환경에서 검증하지 못했습니다. 가짜 API와 모의 런타임으로 요청·응답 흐름만 확인했습니다.
- 배경 제거, 가상 피팅, 로그인, 쇼핑 연동은 범위 밖입니다.
- 서버에는 요청 횟수 제한이 없습니다. 공개 배포 시 `ACCESS_CODE`를 설정하세요.

기능을 정할 때 참고한 제품과 오픈소스는 [docs/reference-analysis.md](docs/reference-analysis.md)에 정리했습니다.
