# 구역 편성 도우미

`index.html`을 브라우저로 열면 바로 사용할 수 있는 구역 편성 도구입니다. 설치할 것이 없고, 입력한 명단은 그 브라우저 안에만 저장되며 외부로 전송되지 않습니다.

## 편성 원칙 (구역장 모임 논의 정리)

1. **구역장을 먼저 세운다.** 구역 수는 구역장 수와 같고, 구역장 가정은 자기 구역에 먼저 배정한다.
2. **가족 단위**(온 가족이 함께 출석)와 **개인**(혼자 출석)을 따로 나눈다.
3. **가족의 기준 나이는 아내 나이로 한다.** 교회 일에는 보통 여자 성도가 많이 나오기 때문이다.
4. 각각 **나이순으로 줄을 세운 뒤 구역마다 한 가정(한 명)씩 돌아가며** 배정한다. 그러면 모든 구역에 연령대가 골고루 섞인다.
   - 나이대별(60·50·40·30대)로 묶는 안도 나왔지만 반대 의견이 있었다. 또래끼리는 시기·질투가 생기기 쉽고, 교회가 직장이라 갈등을 풀기 어렵다. 또 30대는 어르신(권사·장로님)께 배울 기회를 잃는다.
5. **가족을 먼저** 고르게 나눠서 구역마다 일손(부부)이 비슷하게 한다. **개인은 마지막에 쭉 돌려서** 한 구역에 몰리지 않게 한다. 식사·청소 봉사 부담을 고르게 하려는 것이다.
6. 젊은 가정이 또래 없이 한 구역에 혼자 고립되지 않았는지 확인한다. 도구가 경고로 알려 준다.

## 사용법

1. 명단을 입력한다. 직접 입력하거나 엑셀에서 `이름 · 구분(가족/개인) · 나이 · 성인수 · 구역장(O) · 메모` 칸을 복사해 붙여 넣는다.
2. 구역장에 체크한다.
3. **구역 편성 실행**을 누른다.
4. 결과에서 사정이 있는 가정은 이름 옆 선택칸으로 다른 구역으로 옮긴다.
5. 인쇄하거나 CSV로 저장한다.
