# 구역 편성 도우미

`index.html`을 브라우저로 열면 바로 사용할 수 있는 구역 편성 도구입니다. 설치할 것이 없고, 입력한 명단은 그 브라우저 안에만 저장되며 외부로 전송되지 않습니다.

## 편성 원칙 (구역장 모임 논의 정리)

1. **구역장을 먼저 세운다.** 구역 수는 구역장 수와 같고, 구역장 가정은 자기 구역에 고정한다.
2. **가족 단위**(온 가족이 함께 출석)와 **개인**(혼자 출석)을 나눈다. **가족의 기준 나이는 아내 나이로 한다.** 교회 일에는 보통 여자 성도가 많이 나오기 때문이다.
3. 구역장까지 포함해 **모든 구역에 연령대가 골고루 섞이게** 한다.
   - 나이대별(60·50·40·30대)로 묶는 안도 나왔지만 반대 의견이 있었다. 또래끼리는 시기·질투가 생기기 쉽고, 교회가 직장이라 갈등을 풀기 어렵다. 또 30대는 어르신(권사·장로님)께 배울 기회를 잃는다.
4. **젊은 가정은 혼자 두지 않는다.** 두 가정씩 짝짓거나 젊은 개인과 함께 둔다. 고르게 흩기만 하면 오히려 "학위 가정 혼자 외톨이"가 되기 때문이다.
5. **구역마다 다리 역할을 할 중간 연령 가정**(기본 40~59세)을 최소 한 가정 둔다.
6. **일손(봉사 가능 인원)과 성인 수가 구역마다 비슷하게** 한다. 고령, 맞벌이, 주말부부는 "일부"나 "어려움"으로 표시해 실제 일손으로 계산한다.
7. **돌봄이 필요한 분**은 한 구역에 몰리지 않게 나눈다.
8. **함께 / 분리 요청**은 지킨다. 요청은 기간을 정해 제3자가 한 창구로 받고, 사유가 있는 것만 넣는다. 목사님께 직접 요청이 몰리지 않게 하기 위해서다.

## 편성 방법

1. 구역장을 각 구역에 고정한다.
2. 가족, 개인 순으로 나이순 S자(지그재그) 배치를 해서 초안을 만든다. 학교 반편성과 같은 방식이다.
3. 위 원칙을 점수로 매기고, 점수가 낮아지도록 사람(또는 "함께" 묶음)을 옮기거나 맞바꾸기를 수만 번 반복한다.
4. 가장 좋은 안을 보여 준다. "다른 안 보기"를 누르면 같은 조건에서 구성이 다른 안이 나온다.

## 사용법

1. 명단을 입력한다. 직접 입력하거나 엑셀에서 붙여 넣는다. 제목 줄: `이름 · 구분 · 나이 · 성인수 · 구역장 · 봉사 · 돌봄 · 함께 · 분리 · 메모`
2. 구역장에 체크한다.
3. **구역 편성 실행**을 누른다. 결과 위의 점검표에서 원칙이 지켜졌는지 확인한다.
4. 사정이 있는 가정은 이름 옆 선택칸으로 다른 구역으로 옮긴다. 옮기면 점검표와 경고가 바로 다시 계산된다.
5. 인쇄하거나 CSV로 저장한다. 저장한 CSV는 다시 붙여 넣어 불러올 수 있다.
